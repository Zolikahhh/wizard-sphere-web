#  Wizard Sphere Web Project

An interactive, responsive web application designed with a wizard theme. This project demonstrates core frontend web development principles using native web technologies without external framework overhead.

---

##  Features

- **Interactive UI:** Smooth user interactions and event handling powered by native JavaScript.
- **Custom Styling:** Clean layouts, animations, and visual CSS effects (e.g., blend modes and transitions).
- **Responsive Design:** Fully adaptable layout across desktop and mobile devices.
- **Lightweight & Fast:** Zero dependencies, built entirely using pure HTML5, CSS3, and Vanilla JS.

---

##  Tech Stack

- **HTML5:** Semantic document structure
- **CSS3:** Custom styles, animations, and responsive layout
- **JavaScript (ES6+):** DOM manipulation, event listeners, and interactive logic
